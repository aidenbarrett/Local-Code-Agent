# Contributing

Local Code Agent is currently a proprietary project and is not accepting unsolicited
external code, documentation, design or other contributions.

Do not open a pull request containing material you expect the project to incorporate
unless Aiden Barrett has explicitly invited that contribution and the ownership and
licensing terms have been agreed in writing first.

Bug reports and discussion do not grant the project permission to copy third-party
code or other protected material into the repository.

This policy exists to keep the project's ownership and future licensing options clear.
It may change later if the project adopts a different contribution or licensing model.
